#+TITLE: tuisla
#+STARTUP: showall

* tuisla
A Tesla dashboard for the terminal.

Demo data, read-only mode.

* Dashboard
Battery, charging, climate, tyres and locks at a glance.

Refreshes every 5 s.

* Help  =h=
Keys and current settings.

Toggles take effect right away.

* Help: colors  =b=
Off by default; =-c= starts with colors.

* Help: invert  =i=
Inverted screen.

* Help: refresh rate  =+ -=
Refresh interval in 5 s steps.

* Help: units  =u=
Metric or US units, seen on the dashboard.

* Help: style  =s=
Fancy or minimal style.

* Back to dashboard  =h=
US units and minimal style.

Then =s= and =u= switch back.

* Command list  =?=
Every command, by category.

=j= / =k= to scroll.

* Search  =/=
Regex search in the list.

=n= / =N= jump between matches.

* Type a command  =:=
Tab completes, e.g. =charge limit 80=, =temp 22=.

In read-only mode commands are checked but not sent.

* Hotkeys  =H=
One-key commands, e.g. =H= honks.

Not sent in read-only mode.

* Command log  =z=
Every command and its result is logged.

* Modes  =m=
=ro= → =mtm= (MyTeslaMate API) → =vc= (vehicle-command, WIP).
